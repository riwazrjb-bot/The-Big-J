# The Big J

## 1. Planning

### Problem

Job seekers often apply to many jobs through different websites, making it difficult to track their applications, interview stages, preparation notes, and follow-up tasks in one place. **The Big J** will provide a centralized application-tracking system for managing the job-search process.

### Target Users

The primary target users are college students, graduating students, recent graduates, and entry-level job seekers.

### V1 Features

- User authentication
- Create, view, update, and delete job applications
- Track application statuses, such as Applied, Interview, Offer, and Rejected
- Search and filter applications
- Mark applications as favorites
- Add notes to applications
- View a dashboard summarizing application progress

### Future Features

- Interview scheduling and interview-round tracking
- Recruiter and interviewer contact management
- Application and interview reminders
- Job-search analytics and progress reports
- Resume and cover-letter tracking
- Email and calendar notifications

### Project Scope

The initial version will focus on helping users organize and monitor their job applications. Advanced features will be added after the core authentication, CRUD, status tracking, filtering, and dashboard functionality is complete.
